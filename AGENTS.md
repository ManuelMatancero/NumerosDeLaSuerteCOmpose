# AGENTS.md — NumerosDeLaSuerte

Android single-module app (`:app`) built with Gradle Kotlin DSL and Jetpack Compose.

## Quick commands

```bash
# Build debug APK
./gradlew :app:assembleDebug

# Build release AAB
./gradlew :app:bundleRelease

# Run unit tests (JVM only; there is only an example test today)
./gradlew :app:testDebugUnitTest

# Run instrumented tests (requires connected device/emulator)
./gradlew :app:connectedDebugAndroidTest

# Clean
./gradlew clean
```

## Tech stack

- Kotlin 2.0.0, AGP 8.11.2, Gradle wrapper
- `compileSdk = 36`, `minSdk = 24`, `targetSdk = 36`
- Java / JVM target 11
- Jetpack Compose (BOM 2025.12.00) + Compose Compiler plugin
- Navigation Compose, ViewModel Compose, DataStore Preferences, WorkManager
- Retrofit 2.9.0 + Moshi Kotlin 1.15.0 for networking
- Google Play Services Ads + Firebase BoM 33.1.1 + ML Kit Translate

## Architecture

- **Single Activity**: `MainActivity` hosts the entire UI via Compose.
- **Entry point**: `MainActivity` → `AppEntryPoint()` → `AppNavigation()`.
- **Navigation routes**: defined in `AppDestinations` (`ui/theme/nav/Navigation.kt`).
- **Screens**: located under `ui/theme/screen/` (not `ui/screen/`).
- **ViewModels**: `viewmodel/` package.
- **Repositories**: `repository/` package.
- **API layer**: `services/` package (`ApiClient`, `HoroscopeApi`).
- **Application class**: `MyApplication` initializes MobileAds and schedules daily notifications.

## Dependency quirks

- Most dependencies use the version catalog (`gradle/libs.versions.toml`), but some are hard-coded raw strings in `app/build.gradle.kts` (Retrofit, Moshi, Firebase BoM, ML Kit, CardView).
- `play-services-ads` is declared twice: once via catalog (`libs.play.services.ads`) and once as a raw string with a newer version (`24.4.0`). When editing dependencies, check both declarations to avoid version conflicts.

## Build notes

- `isMinifyEnabled = false` in release; ProGuard files are referenced but not actively shrinking.
- `local.properties` is auto-generated by Android Studio and contains `sdk.dir`. Do not commit it.
- No CI workflows or pre-commit hooks exist in this repo.

## Testing

- Only boilerplate example tests exist (`ExampleUnitTest`, `ExampleInstrumentedTest`).
- There are no integration-test prerequisites or fixtures to worry about.

## Runtime behavior

- The app checks internet connectivity on launch (`ConnectivityObserver`) but currently **does not block usage** when offline (the blocking branch is commented out in `MainActivity`).
- `POST_NOTIFICATIONS` permission is requested at runtime on API 33+.
- AdMob `APPLICATION_ID` is hardcoded in `AndroidManifest.xml`.
